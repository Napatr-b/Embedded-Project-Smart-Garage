# บทสาธิต Smart Garage ประมาณ 3 นาที

เตรียม: เปิด Terminal ที่ `smart-garage/web` แล้วรัน `npm.cmd run dev` เปิด URL ที่ Terminal แสดง เลือก Demo Mode แล้วกดรีเซ็ตเดโม ไม่ต้องใช้ ESP32, broker, บัญชี, Sheets หรือ LINE ป้าย “ข้อมูลจำลอง” ต้องเห็นชัด

## 0:00–0:30 ภาพรวม

“Smart Garage เป็นงาน Embedded System ของกลุ่มนอนน้อยนอนไม่พอ Sensor Node อ่าน LDR, DHT22, ENS160 ส่ง UART ให้ Gateway ESP32-S3 เว็บคุย Gateway ผ่าน MQTT วันนี้ใช้ข้อมูลจำลอง ไม่ใช่อุปกรณ์จริงหรือประวัติจาก Sheets”

ชี้ Broker กับ Gateway ที่แยกกัน และเวลาข้อมูลล่าสุด เขตเวลา Asia/Bangkok

## 0:30–1:05 สถานะและการควบคุม

กดเปิด → ชี้ Opening และ pending → รอประมาณ 3 วินาทีเป็น Open → กดปิด → ชี้ Closing → รอ Closed

กดเปิดอีกครั้งแล้วกดหยุดก่อนครบ 3 วินาที → แสดง Fault / หยุด → กด “รีเซ็ต Fault” ในเครื่องมือเดโม อธิบายว่า Fault หลัง Stop เป็นนโยบายของแบบจำลอง ต้องตกลง stop semantics ของ firmware จริงก่อน

“เว็บไม่สรุปว่าประตูเปิดสำเร็จจาก publish แต่รอคำยืนยันหรือสถานะจาก Gateway ปุ่มหยุดนี้ไม่แทนปุ่มฮาร์ดแวร์”

## 1:05–1:35 เซนเซอร์และเหตุการณ์

ชี้อุณหภูมิ ความชื้น LDR raw (ยังไม่ใช่ lux) และ LED แล้ว ENS160: AQI, TVOC และ eCO2 (ค่าประมาณเทียบเท่า ไม่ใช่ CO2 โดยตรง)

กดจำลองรถเข้า/ออก ดูพื้นที่จอดและระยะเปลี่ยน ชี้ Event Log เวลาไทย และกราฟล่าสุด พร้อมตารางอ่านค่ากราฟ

“การตรวจใบหน้าจริงใช้ ESP-WHO บนบอร์ด ตอนนี้ไม่ได้เปิดกล้องหรือทำ AI ใน browser สถานะพื้นที่จอดไม่ยืนยันว่าทางประตูปลอดภัย”

## 1:35–2:20 ทดสอบการขาดการเชื่อมต่อ

กดจำลอง Gateway offline → Broker ยังเชื่อมต่อจำลอง แต่ Gateway ออฟไลน์และทุกปุ่มคำสั่งถูกปิด → กดเชื่อม Gateway กลับ

กดพักข้อมูลแล้วรอ 16 วินาที ระหว่างรออธิบาย timestamp/heartbeat เมื่อขึ้นข้อมูลเก่า ชี้ว่าปุ่มถูกปิดและค่าที่เห็นเป็นค่าครั้งก่อน กดส่งข้อมูลต่อ

กดจำลอง Fault ชี้ว่าปุ่มเปิด/ปิดถูกปิด แต่ Stop ยังใช้ได้เมื่อข้อมูลสด แล้วกดรีเซ็ต Fault

## 2:20–3:00 โครงเชื่อมจริงและข้อจำกัด

เลือก MQTT Mode โดยยังไม่มี `.env` → แสดงยังไม่ตั้งค่า ไม่มีข้อมูล และปุ่ม disabled

“โหมดนี้เป็นโครง integration ต้องตกลง WSS, topics, payload, authentication และ ACL กับเพื่อนก่อน ร่างอยู่ใน integration-contract.md ใช้ commandId และ timeout 8 วินาที ไม่มี motor retry อัตโนมัติ ประวัติจริงจะเก็บ Sheets ผ่าน HTTPS และ LINE ส่งจาก Gateway/backend โดยไม่ใส่ token ใน frontend วันนี้ยังไม่ได้เชื่อมบริการจริงและยังไม่ deploy”

กลับ Demo Mode และจบด้วยภาพรวมโครงการ

ถ้าต้องเดโม timeout เพิ่ม: กดเปิดแล้วกดพักข้อมูลทันที รอ 8 วินาที ระบบจะแจ้งไม่ทราบผล ไม่มี retry จากนั้นกดรีเซ็ตเดโมเพื่อกลับสภาพเริ่มต้น


## ทางเลือกสาธิตเฟิร์มแวร์ (หลัง Upload ด้วยตัวเองเท่านั้น)

ใช้ gateway_bringup แสดง Serial heartbeat และผล Flash/PSRAM โดยไม่ต่อ Servo หากมี config/broker ที่ทีมอนุมัติจึงเลือก gateway_simulated เพื่อแสดงข้อมูลจำลองฮาร์ดแวร์ผ่าน MQTT กับเว็บ ไม่อ้างว่าเป็นเซนเซอร์จริงหรือ ESP-WHO จริง โหมด gateway_mqtt ที่ไม่มี hardware ต้องรายงาน Unknown/null ไม่แต่งค่ามาแทน
